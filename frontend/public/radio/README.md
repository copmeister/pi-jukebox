# Bundled radio artwork

These files are presentation-only station marks. They never provide playback
URLs and are not fetched at runtime.

- `classic-fm.svg` — `https://upload.wikimedia.org/wikipedia/commons/a/ae/Classic_FM_logo.svg`,
  declared as the organisation logo in Classic FM's official homepage JSON-LD,
  retrieved 20 August 2026.
- `capital.png` — `https://imgs.capitalfm.com/images/573609?format=png&signature=fxgDCsRPRQMvt-WaQM8YWFAMFa8=`,
  declared as the organisation logo in Capital's official homepage JSON-LD,
  retrieved 20 August 2026.

Stations without a confidently sourced local asset intentionally use the
existing generated station-mark fallback.
